# uniapp开发的灵活用工系统/仿鱼泡零工平台/多城市智能招聘系统源码/全开源版

源码地址：ym7k.com/19331/

## 🧩 三大角色

### 👷 工人端（找活）

- 微信 / 手机号登录、人脸识别实名、证书上传（电工证、焊工证等）
- **工人技能名片（鱼泡核心）**：工种、工龄、可上岗时间、期望结算、出差意愿、作品图，名片支持海报分享、被雇主检索邀约
- LBS 定位、地图找活，多城市自由切换；筛选：距离、日结 / 周结 / 月结 / 完工结、食宿、工期、工种
- 岗位报名、收藏、内置 IM 隐私聊天、脱敏电话，保护手机号
- **定位打卡记工、工时台账、上岗确认、完工验收、薪资账单、钱包提现、双向评价、黑名单**
- 报名记录、邀约消息、我的名片、收入明细

### 🏗️ 用工端（老板 / 包工头 / 企业）

- 实名 / 营业执照双审核，审核通过才允许发布招工单
- 两种发单模板：【零工招工单（工地 / 短期）】、【常规全职岗位】
- 发布：用工地点、人数、工期、薪资、食宿、进场时间、岗位要求
- 人才库按工种、距离检索，主动邀约工人
- 报名审核、上岗确认、完工验收、评价工人
- 岗位上下架、暂停、刷新、置顶、加急曝光，充值购买推广套餐

### 🧑‍💻 平台总后台（PC）

- 用户、招工单、岗位、名片统一审核，支持先发后审开关、敏感词过滤、举报黑名单
- **多城市分站核心**：分站独立管理员、独立广告、独立定价、分站收益分佣；总站统一风控、统一资金配置；可开启城市代理加盟模式
- 工种库、行业、地区、结算标签后台自定义
- 变现配置：置顶套餐、刷新扣费、会员、接单佣金、代理分成
- 财务模块：充值订单、流水、提现审核、分站对账、资金记录
- 数据大盘：分城市统计岗位发布量、报名量、沟通量、完工成交、资金统计
- 权限分级：运营、财务、客服、分站代理子账号

## ✨ 全开源版本特色（和加密授权版区分）

1. **完整源码无加密**，没有域名授权、机器码绑定，可随意部署多台服务器、深度二次开发，可剥离模块单独拆分使用
2. **混合招聘模式**：一套系统同时跑【工地蓝领零工、班组大包、短期日结】+【企业全职招聘】，后台可关闭任意业务
3. **原生多城市分站架构**，不是简单的定位筛选，分站独立运营、独立收款分成，适合全省布局招合伙人
4. **全套灵活用工闭环**：招工发布 → 报名沟通 → 上岗打卡 → 完工验收 → 结算提现；可加装【平台担保托管发薪、电子劳务协议、灵活用工保险】插件
5. **跨端交付**，UniApp 前端一份代码，同时出小程序、H5、APP，引流入口丰富
6. 代码注释齐全，适合二次开发、学习、承接外包定制
